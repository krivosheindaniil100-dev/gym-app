# Body Twin — цифровой двойник тела

Личное Android-приложение: 3D-модель тела, которая меняется по реальным замерам и по балансу калорий.

## Вкладки
| Вкладка | Что там |
|---|---|
| **Тело** | 3D-модель (крутится пальцем), вес / % жира / мышцы в режиме LIVE, «машина времени» (история и прогноз на 12 недель), контур для сравнения, обхваты модели, энергобаланс, сканирование QR с весов |
| **Питание** | Дневник по приёмам пищи, сканер штрихкодов (Open Food Facts), ввод граммовки с клавиатуры, свои продукты, расход и активность, расчёт нормы КБЖУ, «Что приготовить» — блюда и планы на день под твои БЖУ из 82 рецептов |
| **Тренировки** | Программа под цель (сушка / рекомпозиция / поддержание / набор), дни в неделю, место, интенсивность, приоритетные мышцы, травмы; запись подходов с таймером отдыха; калории идут в расход |
| **Прогресс** | Графики веса, % жира, массы жира и мышц, баланс калорий по дням, итоги по месяцам, сравнение «модель vs весы», список замеров |

## Как считается (строго)
- **Замер с весов — истина.** Между замерами: `Δжир = Σ(съедено − потрачено) / 7700` (7700 ккал = 1 кг жира, 3500 ккал/фунт × 2,2).
- Мышцы и безжировая масса меняются только по замерам.
- Расход = базовый обмен Кэтча–МакАрдла `370 + 21,6 × сухая масса` × коэффициент образа жизни + тренировки по MET (чистый расход `(MET − 1) × кг × ч`). Альтернативы: режим «Шаги» или «Часы» (активные калории из Samsung Health).
- Дни без записей еды не учитываются — забытый дневник не превращается в «голодовку».
- Опционально: автокоррекция расхода по расхождению прогноза с реальными замерами.

## 3D-модель (реалистичный человек)
- **Анатомическая сетка MakeHuman** (CC0, makehumancommunity.org): лицо, глаза, пальцы, мышцы; 490 морф-таргетов
  (пол, возраст, мышцы, жир, обхваты, ягодицы, живот, грудь, форма лица…), сглаживание Catmull–Clark,
  кожа с микрорельефом, глаза с радужкой, короткая стрижка, брови, спортивное бельё, мягкие тени.
  Сборка ассета: `python3 tools/build_human.py base.obj makehuman-1.3.2.whl` → `public/human/`.
- **Физика состава тела** (`src/body/model.ts`): жир распределяется по объёму (0,9 кг/л) по реальным депо;
  обхваты модели меняются ровно так, как требует эта модель: −1 кг жира ≈ −1,2 см талии, −10 кг ≈ −11 см.
- **Твоё телосложение** («Мой аватар»): где у тебя откладывается жир (живот / бока / ягодицы / бёдра / грудь /
  спина / руки), тип фигуры, замеры рулеткой. Персональные обхваты задаются в момент замера; их «жировая» часть
  уменьшается вместе с жиром.
- **Подгонка по фото**: фото спереди и сбоку → MediaPipe Pose (на телефоне, офлайн) → силуэт и 33 точки →
  ширина и глубина на уровнях шеи, груди, талии, бёдер, бедра, голени, плеча → обхваты (точность ±2–4 см).
- **Лицо по селфи**: MediaPipe Face Landmarker (478 точек) → форма лица подгоняется по 10 пропорциям
  относительно «среднего лица», а фото натягивается на лицо (thin-plate spline). Тон кожи, цвет глаз и волос
  определяются автоматически. Нужно нейтральное лицо с закрытым ртом.
- Честно: «копию 1 в 1» по фото с телефона получить нельзя — это параметрическая модель, подогнанная под тебя.

## QR-код с весов
Распознаются JSON, ссылки с параметрами, `ключ=значение` и наборы чисел (числа один раз
сопоставляются вручную, формат запоминается). Если QR содержит только ссылку на облако весов —
приложение предложит ввести цифры с бланка. Пример своего кода: `weight=82.4;pbf=19.5;smm=37.2;vfl=8`.

## Установка
Каждый пуш собирает APK в GitHub Actions и публикует в **Releases** (`BodyTwin-1.0.N.apk`).
Открыть на телефоне → скачать → установить. APK подписан постоянным ключом, поэтому новые версии
ставятся поверх старых без потери данных. Данные хранятся только на телефоне; есть экспорт/импорт.

## Разработка
```bash
npm install
npm run dev        # веб-версия (камера заменяется вводом текста)
npm test           # тесты: правило 7700, парсер QR, реализм модели, замеры по фото
npm run assets     # WASM и модели MediaPipe в public/mediapipe (скачиваются, не в git)
npm run build && npx cap sync android && cd android && ./gradlew assembleRelease
```
Стек: React 19 + TypeScript + Vite, Three.js, MediaPipe Tasks Vision, Zustand, Capacitor 8 (ML Kit barcode scanner, Preferences, Haptics).
